# terrain-classification-tactile-ml

# Terrain Classification for Small-Legged Robots Using Deep Learning on Tactile Data

## Overview
This project explores terrain classification using machine learning and deep learning on tactile sensor time-series data collected from a small-legged robot.

## Objectives
- Understand and preprocess tactile sensor data.
- Build an SVM baseline for terrain classification.
- Develop a 1D Convolutional Neural Network (CNN).
- Compare model performance using accuracy, precision, recall, F1-score, and confusion matrices.

## Methodology
1. Dataset exploration and preprocessing.
2. Feature extraction and SVM baseline implementation.
3. 1D CNN development and training.
4. Model evaluation and comparison.
5. Analysis of results and limitations.

## Repository Structure
- `data/` — Dataset instructions and data access information.
- `notebooks/` — Data exploration and experiments.
- `src/` — Preprocessing, models, training, and evaluation code.
- `results/` — Evaluation metrics and visualisations.
- `docs/` — Project report and presentation.
